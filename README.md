# Homebrew Tap for thand-io

This is the official Homebrew tap for thand-io tools.

## Installation

```bash
# Add the tap
brew tap thand-io/tap

# Install the agent
brew install agent
```

## Available Formulas

### agent

Serverless workflow agent for cloud automation.

```bash
brew install thand-io/tap/agent
```

**Usage:**
```bash
agent --help
```

## Supported Platforms

- ✅ macOS Intel (x86_64)
- ✅ macOS Apple Silicon (arm64)  
- ✅ Linux AMD64
- ✅ Linux ARM64
