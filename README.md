# Homebrew Tap for thand-io

This is the official Homebrew tap for thand-io tools.

## Installation

```bash
# Add the tap
brew tap thand-io/tap

# Install the thand agent
brew install thand
```

## Available Formulas

### thand

Serverless workflow agent for cloud automation.

```bash
brew install thand-io/tap/thand
```

**Usage:**
```bash
thand --help
```

## Supported Platforms

- ✅ macOS Intel (x86_64)
- ✅ macOS Apple Silicon (arm64)  
- ✅ Linux AMD64
- ✅ Linux ARM64
